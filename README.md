# Rise of the Penguins GB - Snap Package

This repository contains the Snap package for Rise of the Penguins GB.

## Building Locally

```bash
snapcraft
```

## Installing

```bash
sudo snap install rise-of-the-penguins-gb
```

Or install from the Snap Store:

```bash
sudo snap install rise-of-the-penguins-gb
```

## Game Files Required

The following game files need to be in the root of this repository:
- `rise of the penguins gb.x86_64` - Main executable
- `rise of the penguins gb.pck` - Game data
- `libgodotsteam.linux.template_release.x86_64.so` - Steam integration library
- `libgodot_boy.linux.x86_64.so` - Godot Boy extension
- `libsteam_api.so` - Steam API library
